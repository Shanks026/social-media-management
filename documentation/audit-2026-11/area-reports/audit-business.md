# Cleanup / Maintainability Audit — Business & Sales Features

Scope: Prospects, Proposals, Finance, Documents, Reports, Ads/Partnerships. Cleanup only (no security analysis). No files were edited. Everything below was checked with grep/eslint against `main` @ 1d403e7.

Legend: **REMOVE** · **CAN STAY** · **NEEDS IMPROVEMENT**

Cross-cutting facts:
- **No tests** exist for any feature in this area. `src/tests/` has only `campaigns/` and `comments/`.
- **The API convention doesn't match the code.** `.claude/rules/api-conventions.md` says "Never wrap mutations in React Query hooks at the API layer". But `invoices.js`, `expenses.js`, `transactions.js`, `proposals.js`, `prospects.js` and `prospectActivities.js` all export `useCreateX` / `useUpdateX` / `useDeleteX` mutation hooks (for example `src/api/invoices.js:139,226,345,396,420,443,463`). Only `documents.js` follows the rule, with plain async functions (`src/api/documents.js:97-324`). Either update the rule to allow both, or pick one pattern.
- ESLint reports 27 errors and 13 warnings across these folders. Most are unused imports or vars (listed per feature below).
